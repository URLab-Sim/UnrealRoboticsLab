# URLab completion status

URLab targets **MuJoCo 4.0.2** (`7252110fb`, `mjVERSION_HEADER 4000002`) with the clean-slate `MuJoCoSpec` (`mjSpec`) authoring layer and typed simulation, render-server, viewer, and editor services.

## Established baseline

URLab has distinct simulation, render-server, viewer, and editor APIs. ZMQ carries commands, with local SHM bulk data or network data; gRPC (`dm_env_rpc`) exposes URLab rendering extensions on Linux with network data. XML plus assets, MJZ, and MJB are primary model inputs.

- **MuJoCo 4.0.2 integration:** Supports by-reference textures (`tex_adr == -1`, `mj_loadTexture`), `mj_embedAssets`, per-element `flex_matid`, updated `mjcf.schema` (with `<composite>` and `<flexvert>` removed in MuJoCo 4), and `mjsCompiler` export flags (`savecompiled`, `savecanonical`, `saveinertial`).
- **Clean-slate `MuJoCoSpec` layer:** `UMJModelComponent`, `UMJBodyComponent`, `UMJFrameComponent`, `UMJGeomComponent`, `UMJJointComponent`, `UMJSiteComponent`, `UMJCameraComponent`, `UMJLightComponent`, `UMJAttachComponent`, `UMJActuatorComponent`, `UMJSensorComponent`, `UMJTendonComponent`, `UMJAssetLibrary`, and `FMJXmlImporterExporter` marshal directly to/from `mjSpec` via structs and marshalers generated by `Tools/SpecCodegen/generate_ue_spec.py`.
- **Neutral renderer & typed bridge:** The renderer remains physics-independent, consuming neutral scenes, resources, and Cartesian frames. The companion `URLab_Bridge` repository provides typed `Connection`, `SimulationClient`, `RenderClient`, `ViewerClient`, `EditorClient`, `PoseStreamPublisher`, `OutputReader`, and `RenderPool` clients.

For service boundaries and authority rules, see [Intended Design](intended_design.md) and [Transport Contract](transport_design.md).

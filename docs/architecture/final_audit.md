# Core architecture closeout audit

Status: **Linux implementation and named acceptance gates complete**, 2026-09-23. This review compares the current implementation with the [intended design](intended_design.md). The implementation paths below are source evidence, while the results at the end identify what has actually run. The [workspace evidence index](../../../audit_docs/README.md) identifies the current package and earlier retained reports.

| Boundary | Current implementation and invariant |
|---|---|
| Authoring to simulation | `Source/URLab/Private/MuJoCo/Authoring/MjAuthoringCompiler.cpp` assembles placed authoring sources into an owned `FMjOwnedModelCandidate`; `AMjManager.cpp` hands that candidate to `MjSimulationWorldSubsystem.cpp`. A manager does not own runtime model/data or register a simulation service. `AMjArticulation` is an authoring Actor. |
| Independent simulation | `MjSimulationWorldSubsystem.cpp` owns activation/install/clock/bridge attachment; `MjSimulationRuntime.cpp` owns model/data, control authority, step/reset, observations and validated state snapshots. Runtime state is model-level and does not use articulation actors. Failed candidate preparation does not replace the installed model. |
| Neutral rendering | `Source/URLab/Private/Render/` builds scenes/resources from neutral `FRenderScene` and `FRenderFrame` values and shares the production scene actor with viewport/camera capture. This directory has no MuJoCo include, `mj_step`, FK or wire decoder dependency. `MjRenderSceneAdapter.cpp` and `MjRenderKinematics.cpp` own MuJoCo extraction and qpos-to-Cartesian `mj_forward`; the latter is not integration stepping. |
| Scene and pose ownership | `RenderServerWorldSubsystem.cpp` and `ViewerWorldSubsystem.cpp` enforce one active owner and expected scene revision before installation or frame mutation. `RenderWorldSubsystem.cpp` stages a replacement scene, cancels old capture jobs before commit, and publishes a fresh generation/revision. Old-revision pose submissions are rejected. Viewer stream producer identity remains distinct from a viewer's locally patched revision. |
| Persistent scene edits | `RenderScenePatch.cpp` validates an entire material/geom/light/camera/environment/visualization patch before changing the installed scene. Render/viewer workflow `PatchScene` copies the active scene/resources/applied frame, stages an actor, advances the local revision and rebases MuJoCo visualization. Static scene edits remain in the neutral scene when later qpos or stream frames update dynamic poses. Full installation remains the path for topology/resource replacement. |
| Capture and history | `RenderCameraSubsystem.cpp` runs bounded exact jobs with retained results and separate bounded history. Results identify scene and source frame; scene mutation cancels pending old-scene work. `RenderServerWorldSubsystem.cpp` now applies retained-job count and serial guards to both fresh captures and history-query handles. Live display may coalesce frames; exact accepted jobs have terminal status. |
| Transport and bridge | `Bridge/RpcDispatcher.cpp` routes typed operations with declared services/authority; `Wire/OperationSchema.cpp` rejects unknown nested fields. The current generated inventory has 74 active operations plus two lifecycle operations; 19 retired operations are absent. `Transport/ShmExactPayload.cpp` and the payload store retain immutable exact data separately from latest-frame streams. ZMQ commands with negotiated SHM/network data and gRPC render extension use the explicit workflow services. The old SHM RPC command ring is removed. |
| Python API | The sibling `URLab_Bridge/src/urlab_client/` exports passive `Connection` plus separate simulation, render, viewer, editor, publisher and reader clients. Pool/process work is separate from owner credentials. The old universal runtime-articulation facade and implicit connect/start behavior are removed. |

Legacy source-reference closure found no uses of `UMjPhysicsEngine`, `FMjRenderSnapshot`, `UMjDebugVisualizer`, `UMjOverlayRenderer`, `EMjStepMode`, `StatePushed`, removed event delegates, or the old skin/entity-control classes. The manager-owned runtime, old simulate/twist UI assets and hard-coded asset load paths are gone. Dead `StateSourceEndpoint` and `ControlPort` settings and their parsers were removed. The internal `EMjDrive` boot routing value remains an implementation detail derived from `-URLabWorkflow`; the parser rejects the retired `-URLabDrive` flag. The obsolete `BP_RandomActions` runtime-controller demo was removed after its editor compile failed against retired per-component actuator controls; no other source or content referenced it.

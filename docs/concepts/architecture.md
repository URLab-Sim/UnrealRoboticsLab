# Architecture

URLab separates model authoring, simulation, neutral rendering and transport. `AMjManager` and articulation actors provide authoring sources; a world-owned simulation subsystem owns the compiled MuJoCo model, data, clock, control authority and observations. The renderer consumes neutral scene, resource and Cartesian frame values. A MuJoCo adapter extracts those values from models or derives frames from `qpos` with `mj_forward` without advancing physics.

Render and viewer workflows have explicit owners, scene revisions and source installation. They accept XML with assets, MJB, MJZ or neutral sources. Render capture jobs return retained exact results; live camera and pose streams have their own advertised descriptors. The [intended design](../architecture/intended_design.md) defines these boundaries, [completion status](../architecture/completion_status.md) records verified paths and limitations, and [transport design](../architecture/transport_design.md) explains commands and data.
